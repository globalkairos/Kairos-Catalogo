# Kairós Catálogo
Catálogo web de Kairós con botones de consulta por WhatsApp.

Antes de publicar:
1. Reemplazá `5490000000000` en `app/page.js` por el WhatsApp de Kairós, con código de país y sin + ni espacios.
2. Subí tus fotos a `public/` y cambiá los nombres en `app/page.js`.
3. Actualizá precios y descripciones.
